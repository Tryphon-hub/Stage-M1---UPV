Comment obtenir le graphe

Le script parcourt Software/, HeavyFiles/, Bibliography/ et PlotNeuralNet/, puis écrit quatre vues du même graphe dans tools/out/. Relancez-le après chaque refactor : c'est la seule façon que la carte reste juste. 

# graphe complet + arborescences depuis les 4 racines
python tools/depgraph.py

# cibler d'autres racines
python tools/depgraph.py --roots main.py Training_Net.m

# rendu image (nécessite Graphviz — absent de ce poste)
python tools/depgraph.py --svg

Ce que le script fait que grep ne fait pas

  • Il retire les commentaires avant de chercher les appels — MATLAB % et blocs %{ %}, Python #. C'est ce qui distingue Opt.m (trois appels, tous commentés) de Opt_Stress.m.
  • Il résout l'ombrage du chemin MATLAB : deux SolveFE.m existent, un seul s'exécute.
  • Il lit le MATLAB niché dans les chaînes Python, y compris les blocs rf"""…""" passés à eng.eval().
  • Il ignore les homonymes Python : GenTopology est réimplémenté en Python dans topology_utils.py et n'appelle jamais GenTopology.m.

Toutes les entrées Python

Treize scripts exécutables partagent cinq modules. Aucun n'est importé par un autre : ce sont des points d'entrée, pas du code mort. Les huit TopOpt_* ont un graphe de dépendances rigoureusement identique, à l'exception de _seed qui importe en plus train et evaluate directement.

Hors du pipeline

Trois familles bien distinctes, qu'il ne faut pas traiter pareil : du code mort à supprimer, des scripts autonomes encore utiles, et des dépôts tiers qui ne vous appartiennent pas.

Le piège

Deux SolveFE.m, un seul s'exécute

Tous les scripts font addpath OT_Functions puis addpath OT_Software. Or addpath préfixe le chemin : le dernier ajouté passe devant. C'est donc la version OT_Software qui gagne — ce que confirment les quatre sites d'appel, qui utilisent tous sa signature.

Avant de supprimer

Les douze Mort ci-dessus sont sûrs au sens du graphe statique. Restent deux angles morts qu'aucun analyseur ne couvre : un appel construit dynamiquement (feval, eval avec un nom assemblé) et un appel depuis un fichier hors des dossiers scannés. Un grep du nom sur tout le dépôt avant chaque suppression suffit à lever le doute.
